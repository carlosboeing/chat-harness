# Workspace Map

## Harness state
- Current trip-planning state → `.chat-harness/workstreams/`

## Domain sources
- confirmed reservations → `Bookings/`
- current itinerary artifact → `Itinerary/`
- live destination research → current authoritative public sources
- durable traveller constraints → owning traveller/family source; retrieve when relevant instead of duplicating

## Authority
Research and draft itinerary changes are non-consequential. Booking, cancellation, payment, or changes to an existing reservation require explicit human approval at the action boundary.
