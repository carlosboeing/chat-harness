# Security policy

## Supported version

Security fixes are applied to the current v0.x line while Chat Harness is pre-1.0.

## Reporting a vulnerability

Do not publish exploit details, credentials, private payloads, or sensitive reproduction data in a public issue.

Use GitHub's private vulnerability reporting / Security Advisory flow for this repository when available. If that channel is unavailable, contact the maintainer through the repository owner's GitHub profile before sharing sensitive details.

A useful report includes the affected commit/version, component, authority/data boundary involved, minimal privacy-safe reproduction steps, and observable impact.

## Scope reminders

Chat Harness does not claim that an AI host, GitHub-hosted runner, or Playwright browser is a complete security sandbox. Security reports about privilege expansion, Source Policy bypass in Chat Harness-controlled paths, path-containment failure, persistent-transport confidentiality leakage, approval bypass, or capability contract escape are especially relevant.
