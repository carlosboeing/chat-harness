# Chat Harness v0.1.1

**Harness engineering for AI assistants.**

v0.1.1 is a release-engineering follow-up to the initial v0.1.0 publication. The Chat Harness product contracts and CLI behaviour are unchanged; this release aligns the package version with the public release pipeline and establishes the normal tagged-release path.

## Changes since v0.1.0

- package version advanced to `0.1.1`;
- public GitHub repository identity is `carlosboeing/chat-harness`;
- the durable release workflow now supports semver tag pushes;
- tagged releases build and smoke standalone binaries for Linux x64/arm64, macOS x64/arm64 and Windows x64;
- tagged releases build and validate the bundled npm/Node CLI;
- npm publication uses trusted publishing/OIDC after the initial package bootstrap;
- GitHub Release assets include native binaries, SHA-256 sidecars and the npm tarball;
- the workflow smoke-checks the published npm package after registry propagation.

## Compatibility

There are no intentional Workspace, Workstream, Source Policy, CLI, capability-contract or GitHub-extension behaviour changes relative to v0.1.0.

The real ChatGPT host-binding smoke remains separately pending, so ChatGPT compatibility remains documented rather than end-to-end verified.
