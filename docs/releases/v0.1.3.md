# Chat Harness v0.1.3

**Harness engineering for AI assistants.**

v0.1.3 is a release-engineering patch. It does not intentionally change Chat Harness Workspace, Workstream, Source Policy, capability, or host-binding behaviour.

## Release engineering

- makes a merged release PR the normal release trigger instead of requiring a maintainer-pushed tag;
- treats ordinary `main` merges with an unchanged package version as explicit no-ops;
- requires a stable increasing SemVer version and matching `docs/releases/vX.Y.Z.md` release notes before publication;
- re-runs deterministic qualification and builds/smokes standalone and npm artifacts from the exact protected-`main` merge commit;
- creates the release tag automatically after qualification;
- publishes npm through trusted publishing/OIDC and creates the matching GitHub Release;
- checks existing tag/npm state for safe recovery and refuses mismatched published artifacts;
- keeps manual workflow dispatch build-only and retains tag-push publication only as a recovery path;
- adds CI regression coverage that parses GitHub workflow YAML after an invalid-workflow failure exposed the gap.

This release is also the first end-to-end production test of the release-PR publication path.
