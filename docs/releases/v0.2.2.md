# Chat Harness v0.2.2

This patch release polishes the interactive setup wizard after live testing of v0.2.1.

## Setup wizard presentation

- adds a highlighted `Important` callout for ChatGPT users during first-time setup;
- uses clearer Google Drive guidance: make sure the Workspace is a Google Drive folder before continuing;
- explains that ChatGPT connects to that folder so it can keep using the latest Workspace files over time;
- keeps the Google Drive guidance scoped to ChatGPT rather than implying it is a universal Chat Harness requirement.

## Consistent terminal UI

- renders setup information using Clack UI primitives instead of mixing prompts with raw stdout blocks;
- keeps the introduction, Workspace identity, optional-folder guidance, review, completion, and next steps in one visual language;
- simplifies the already-present optional-folder case, such as `Trips/`, without repeating explanatory copy unnecessarily.

## Workspace tree readability

- keeps the full Workspace tree and deterministic ordering introduced in v0.2.1;
- suppresses repeated child status labels when the parent already communicates the same state;
- preserves meaningful mixed-state labels such as `already there` and `updated`.

## Scope

This release is presentation-only. It does not add storage-provider detection, new setup decisions, provider abstractions, or changes to the Workspace contract.

## Upgrade

npm:

```bash
npm install -g chat-harness@latest
chat-harness --version
```

Standalone installer:

```bash
curl -fsSL https://raw.githubusercontent.com/carlosboeing/chat-harness/main/install.sh | sh
```
