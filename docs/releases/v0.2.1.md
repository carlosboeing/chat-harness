# Chat Harness v0.2.1

This patch release focuses on setup usability, local development workflow, and distribution reliability.

## Guided setup

- adds a clearer first-run setup introduction and distinguishes first-time setup from reruns;
- asks what the Workspace is mainly for using plain-language purpose labels instead of leading with specialist terminology;
- explains optional organizational folders before asking whether to create them;
- shows whether suggested folders are new or already present;
- keeps existing optional folders visible in the final review instead of omitting them when no filesystem operation is needed;
- renders the complete resulting Workspace tree before setup with deterministic, user-friendly ordering;
- replaces implementation-oriented prompts and receipts with a friendlier confirmation and completion summary;
- preserves exact setup operations in JSON and non-interactive output for automation.

## ChatGPT onboarding and documentation

- makes the Google Drive + ChatGPT Project Source path explicit as the current reference setup;
- expands the beginner Getting Started guide and CLI reference;
- improves ChatGPT Project connection guidance, including Project Sources and Project Instructions;
- updates README and specialist documentation to match the guided setup flow.

## Local unreleased builds

- adds `bun run install:local` for testing the current checkout through the standalone binary path without cutting a release;
- identifies local builds as `<package-version>-<short-git-sha>[-dirty]`;
- verifies the installed binary and checks PATH precedence.

## Reliability

- expands packaged/distribution smoke coverage for command help, cwd-based setup, specialists, validation, and doctor;
- fixes `doctor` to match the npm runtime requirement of Node.js 22.12.0 or newer;
- adds deterministic tests for setup tree ordering and existing optional-folder presentation.

## Upgrade

npm:

```bash
npm install -g chat-harness@latest
chat-harness --version
```

Standalone installer:

```bash
curl -fsSL https://raw.githubusercontent.com/carlosboeing/chat-harness/main/install.sh | sh
```

After upgrading, rerun `chat-harness setup` in an existing Workspace to use the improved guided setup and refresh recognized managed files when needed.
