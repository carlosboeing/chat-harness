# Chat Harness v0.1.2

**Harness engineering for AI assistants.**

v0.1.2 is a packaging hotfix for the npm/Node distribution.

## Fixes

- fixes the published npm CLI failing at startup with `Cannot find module 'ajv/dist/2020'`;
- replaces runtime `createRequire()` loading of Ajv 2020 with a static import that Bun can include in the bundled Node CLI;
- explicitly builds the npm CLI with bundled packages;
- derives `chat-harness --version` from `package.json` instead of a hard-coded version;
- adds a clean-install npm smoke that packs the real tarball, installs it into an empty temporary project with lifecycle scripts disabled, and exercises `--version`, `--help`, `setup --json`, and `validate --json`;
- runs that consumer-style smoke in both normal CI and release qualification.

There are no intentional Workspace, Workstream, Source Policy, capability-contract, or host-binding behaviour changes in this patch.
